My Academic Tracker

My Academic Tracker is a mobile application I built to keep track of my school terms, courses, and assessments. I can add, edit, and delete records, search my courses across all terms, generate a report, and log in with a hashed password.

I built it with C# and .NET MAUI, and it uses a SQLite database.

Download the application (APK)

This page is my cloud deployment for the WGU D424 capstone. The APK installs on an Android device or emulator.
